# 动物救助照片分类与人工复核平台

面向动物救助照片整理的本地实验原型：模型先给出猫、狗等已知类别建议，工作人员确认或更正；复核记录可以追溯并导出为新数据集。

## 运行

安装 Python 依赖后运行 `python app.py`，访问 `http://127.0.0.1:5088`。首次使用请在页面创建本地账户。运行后数据和模型保存在本机 `data/` 目录；该目录不会上传到仓库。

## 当前基线

当前训练数据为 CIFAR-10 的猫、狗、鸟三类低分辨率图片。独立测试准确率：FCN 59.07%，CNN 73.70%。这只是课程实验基线，尚未在动物救助现场照片上验证；系统不能识别品种、个体身份或健康状态，也不具备开放集未知类别拒识能力。

## 复核流程

登录后进行分类，可将结果送入人工复核队列。确认或更正类别后，系统保存图片、模型版本和说明；确认样本可导出为按类别整理的 ZIP，再作为新数据集版本导入。请保持独立测试数据隔离。

本项目为本地课程实验原型，不建议直接暴露到公网。真实救助场景使用前，应先取得图片授权，并以按动物个体独立划分的现场数据评估模型。

## 在线静态演示

GitHub Pages 展示界面与示例数据；模型推理、登录、上传、训练和保存需要本地 Flask/PyTorch 服务。


## 恢复已训练模型和数据集

1. 从 [v1.0.0 发布页](https://github.com/LH-0909/animal-rescue-image-classifier/releases/tag/v1.0.0) 下载“实验恢复包.zip”。
2. 将压缩包解压到项目根目录，确保 `data/platform.db`、`data/images/` 和两个 `.pt` 文件位于项目目录下的 `data/` 内。恢复前请备份现有 `data/`，避免覆盖自己的数据。
3. 安装依赖并运行 `python app.py`。打开页面并注册本地账户，即可使用恢复的训练数据、模型和实验记录。

恢复包包含数据集图像、数据划分、模型权重与配置、训练曲线及评估记录；不包含账户密码、会话密钥或小组分工。完整 CIFAR-10 原始档案也在发布页提供。
