# 动物救助照片分类与人工复核平台

面向动物救助照片整理的本地实验原型：模型先给出猫、狗等已知类别建议，工作人员确认或更正；复核记录可以追溯并导出为新数据集。

## 运行

安装 Python 依赖后运行 `python app.py`，访问 `http://127.0.0.1:5088`。首次使用请在页面创建本地账户。运行后数据和模型保存在本机 `data/` 目录；该目录不会上传到仓库。

## 当前基线

当前训练数据为 CIFAR-10 的猫、狗、鸟三类低分辨率图片。独立测试准确率：FCN 59.07%，CNN 73.70%。这只是课程实验基线，尚未在动物救助现场照片上验证；系统不能识别品种、个体身份或健康状态，也不具备开放集未知类别拒识能力。

## 复核流程

登录后进行分类，可将结果送入人工复核队列。确认或更正类别后，系统保存图片、模型版本和说明；确认样本可导出为按类别整理的 ZIP，再作为新数据集版本导入。请保持独立测试数据隔离。

本项目为本地课程实验原型，不建议直接暴露到公网。真实救助场景使用前，应先取得图片授权，并以按动物个体独立划分的现场数据评估模型。
